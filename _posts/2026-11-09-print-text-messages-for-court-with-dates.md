If a landlord dispute, an HR complaint, or a small claims case depends on what someone texted you, the other side has to be able to read it. They will need the messages in order, with dates. [PlainThread](/apps/plainthread/) turns an SMS backup or a WhatsApp export into a PDF. Every message shows the sender, date, and time, and the PDF has day headings and page numbers. PlainThread is a formatting tool and does not give legal advice. Each court or agency decides whether it accepts a printout, so ask them first. Keep the original messages either way.

These steps follow the Play listing as of November 2026. Every feature is included and there is no message cap. There is no subscription, no in-app purchase, and no watermark.

## Get the messages into a file

1. For text messages, back up the phone with an app that saves an `.xml` file.
2. For WhatsApp, open the chat and tap ⋮ › More › Export chat. Share the `.txt` or `.zip` to [PlainThread](/apps/plainthread/), or save it and open it later.
3. Open the file in PlainThread. For an SMS backup, pick the conversation you need.

PlainThread does not ask for permission to read your messages. It reads only the file you give it. For a closer look at both imports, see [how to turn a WhatsApp chat or SMS backup into a PDF](/2026/11/08/export-whatsapp-or-sms-to-pdf.html).

## Check the record before you print

A printout that leaves things out can hurt you later, so this part is worth a few minutes.

1. Read the preview. It shows who took part, how many messages there are, and the first and last dates. Check that these match what you remember.
2. Read the completeness check. It tells you in plain language if only one person's messages were found, or if attachments are named but were not included. It also flags media and deleted messages the export left out, long gaps, and exports that may have hit a size limit.
3. Look at any line it says is not part of a message. Nothing gets dropped without a warning.
4. If a date could be read as day/month or month/day, confirm which one is right. Nothing prints until you do.
5. For an SMS backup, read the reminder about RCS (chat-feature) messages. They are often missing from an SMS backup. Unsent drafts are counted too.

## Set up the PDF for a filing

1. Print the whole chat or only a date range. "All" means every message.
2. Add an exhibit or case label. It appears on every page.
3. Choose A4 or Letter.
4. Keep the export-record page. It lists the source file names, SHA-256 fingerprints, message counts, date settings, time zone, and app version. That helps whoever reads it see how the printout was made.
5. Share, print, or save the PDF wherever you like.

Pages are numbered like "Page 3 of 12". Both sides of an SMS conversation are included, with times. Attachments are listed by file name at the point they were sent. Right-to-left scripts, accents, and emoji are kept.

## When this is the wrong tool

The PDF can only show what is in the file you provide. Deleted messages, media the export left out, and RCS messages missing from an SMS backup cannot be added back. If the message that matters was sent over chat features and is not in the backup, PlainThread cannot print it. It also cannot prove that a file was never edited. If that is what you need, the printout alone will not settle it. Use it only for conversations you took part in.

PlainThread has no internet permission, so the chat stays on the phone until you share the PDF. There are no ads, no analytics, and no account. Working copies are deleted when you close the chat. The app is not affiliated with or endorsed by WhatsApp, Meta, or any SMS backup app.
